MCP Configuration

Use this snippet to connect the Hirely MCP server to your AI assistant (e.g. Roo Code, Cursor, Claude Desktop, etc). Just paste it into your MCP settings and replace <YOUR_TOKEN> with your generated API key.

mcp-config.json 
{
  "mcpServers": {
    "hirely-backend": {
      "type": "remote",
      "url": "https://hirely-api.up.railway.app/v1/mcp",
      "headers": {
        "Authorization": "Bearer <YOUR_TOKEN>"
      }
    }
  }
}

Note: Some IDE extensions might use "mcp" as the root key instead of "mcpServers". Adjust according to your extension's documentation.
